# Velner Sortie Strat — run 9 boss (VF)

Traduction française organisée de la vidéo de Velner sur le run Sortie 9 boss (FFXI),
en setup PLD/DNC/BRD/RDM/COR/GEO, tous sub DRK.

**Page en ligne :** https://ejouanchicot.github.io/velner_sortie_strat/

## Contenu

- Route complète : D (Degei) → H (Aita) → A (Ghatjot) → B (Leshonn) → C (Skomora) → G (Triboulex) → F (Gartell) → E (Dhartok) → Aminon
- Buffs, debuffs et rôle exact de chaque job pour chaque boss
- Procs des shards A, B, C et D
- Table des procs élémentaires de Degei
- Gestion des rolls et préservation des 11 pour le COR
- Section Aminon détaillée : cadence des Absorb-TP, set macc/Fast Cast, séquence Grand Pas du DNC
- Glossaire des termes massacrés par la transcription automatique de YouTube

Les noms d'abilities, de sorts, de weapon skills et de mobs sont laissés en anglais, comme en jeu.
